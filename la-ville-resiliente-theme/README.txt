=== La Ville Resiliente WordPress Theme ===

A clean, minimal WordPress theme for blogging about environmental sustainability and energy transformation in Abidjan.

== Installation ==

1. Download the theme folder: la-ville-resiliente-theme
2. Compress it as a .zip file (la-ville-resiliente-theme.zip)
3. In WordPress Dashboard → Appearance → Themes → Add New → Upload Theme
4. Upload the .zip file and click "Install Now"
5. Click "Activate" when installation completes

== OR Manual Installation ==

1. Upload the entire 'la-ville-resiliente-theme' folder to `/wp-content/themes/`
2. Go to WordPress Dashboard → Appearance → Themes
3. Find "La Ville Resiliente" and click "Activate"

== Setup After Activation ==

1. **Set Homepage Title:**
   - Go to Settings → General
   - Set "Site Title" to "La Ville Resiliente"
   - Set "Tagline" to your description

2. **Create Navigation Menu:**
   - Go to Appearance → Menus
   - Create a new menu called "Primary Menu"
   - Add pages:
     * Home (link to homepage)
     * About (create an About page first)
   - Under "Menu Settings", check "Primary Menu"
   - Click "Save Menu"

3. **Create About Page:**
   - Go to Pages → Add New
   - Title: "About"
   - Add your content and contact form
   - Publish

4. **Create Blog Posts:**
   - Go to Posts → Add New
   - Write your content
   - Add Featured Image (for the card thumbnail)
   - Assign Categories
   - Publish

5. **Set Homepage to Show Posts:**
   - Go to Settings → Reading
   - Select "Your latest posts" under "Your homepage displays"
   - Save Changes

== Features ==

- Clean, minimal design
- Responsive (mobile-friendly)
- 3-column blog grid on homepage
- Beautiful single post layout
- Custom logo (zigzag SVG)
- Google Fonts (Roboto + Open Sans)
- Support for Featured Images
- Category display on cards

== Customization ==

Colors are defined in style.css:
- Primary color (terracotta): #CC785C
- Text color: #3F3831
- Background: #F0F0EB

To change colors, edit the :root variables in style.css
